# Менеджер задач

Консольная программа на Go для управления списком задач


## Возможности

- Просмотр всех задач.
- Фильтрация задач по статусу.
- Добавление новых задач через консольный ввод.
- Изменение статуса существующей задачи по её ID.
- Выход из программы.

## Что изменилось в HW-05:
- Задачи теперь хранятся в удобных структурах (как карточки с полями), а не в разрозненных массивах.
- Добавлен "умный" конструктор, который сам выдает ID, ставит время создания и проверяет правильность данных.
- Задачи теперь могут красиво выводиться на экран одной строкой.

## Что изменилось в HW-06 (Хранилище):
- Создан пакет `internal/storage` с типом `MemoryStorage`.
- Реализовано хранение задач в памяти с использованием слайса и мапы (для быстрого поиска по ID).
- Написаны методы: Add, GetByID, GetAll, Update, Delete, FilterByStatus.
- Обработаны ошибки дублирования ID и отсутствия задачи.
- `main.go` полностью переписан: теперь он использует хранилище и имеет полное консольное меню с удалением задач.
